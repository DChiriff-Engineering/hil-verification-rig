# Fault Injection Plan

Planned injectors:

- fixed value override;
- slow threshold ramp;
- abrupt step fault;
- frame dropout;
- CRC/checksum corruption;
- repeated/skipped sequence numbers;
- frozen sensor;
- bounded noise;
- implausible slew;
- actuator-response mismatch (stretch).

Fault campaigns will be deterministic and reproducible by configuration/seed.
