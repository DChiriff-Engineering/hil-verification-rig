# Roadmap

1. Freeze requirements, architecture, protocol, and pin plan.
2. Bring up both Picos and the UNO with unique firmware identity responses.
3. Implement DUT sensor parser, state machine, physical outputs, and diagnostics.
4. Implement HIL sensor generator, simple closed-loop plant, and fault injection.
5. Build Python device drivers, fixtures, scenario API, and first end-to-end pytest.
6. Add nominal, boundary, timing, and fault campaigns.
7. Add independent UNO witness.
8. Add evidence bundles, reports, and requirements traceability.
9. Run regression/robustness campaigns and document at least one defect caught by the rig.
10. Add software-only CI and recruiter-facing documentation/demo.
